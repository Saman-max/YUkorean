## 验证

`npm test` 包含：

- 课程数据引用、40 音唯一性、题目正确选项完整性。
- 间隔复习：首次记住、递增间隔、遗忘后重试、最长间隔。
- 当前日期与连续天数计算。
- 备份校验、重复记录与非法字段过滤。
- DOM 交互集成：学习字母 → 单词收藏与复习 → 日记保存 → 语法作答 → 阅读 → 情境对话 → 完成测验与评分 → 词句解析 → 修改称呼。
- 用户输入转义，避免将昵称作为 HTML 执行。

`npm run check` 遍历构建页面，检查本地 HTML、图片、样式和 CSS 引用；构建支持根路径和 GitHub Pages 仓库子路径。

已在真实 Chrome 浏览器检查官网首页与学习中心，并验证官网进入学习中心的跳转。学习中心截图见 [实际预览](screenshots/learning-center.jpg)。手机宽度控制未能在本次浏览器连接中生效，因此未完成真实移动视口的视觉核验；移动样式已实现，但不能据此声称手机端逐像素验证通过。

DOM 集成测试不等于真实浏览器视觉验证。未逐页截图比较的内容，不表述为与原站逐像素一致。

## 数据处理

学习功能不向服务器上传笔记、对话或备份。称呼、课程掌握、收藏、复习时间、练习分数、学习日期和句子保存在 `yukorean-progress`。主题与展示页的少量收藏另有浏览器本地键。清理浏览器数据会删除记录，建议定期导出备份。

原站“隐私政策”和“条款”不作为本项目协议使用，本项目的相关页面另作说明。网站不请求账户密码、不处理订单、不调用原站会员服务。
