# YUKorean

对 [Tori Korean](https://torikorean.com/) 的公开产品进行探索、结构拆解与独立功能复刻。

官网保留参考站公开的页面结构、样式和插画；学习中心由本项目独立编写，可在 GitHub Pages 运行。不是原站源码，不连接原站账号、支付或付费课程后台。新增独立云端账号与学习数据库，AI 由服务端接入 OpenAI。

第二版的课程与后台说明见 [云端学习服务](docs/CLOUD_BACKEND.md)。

- [产品拆解](docs/PRODUCT_ANALYSIS.md)：定位、学习闭环、增长、会员、技术判断与实现路线。
- [实现清单](docs/IMPLEMENTATION.md)：已实现内容、复刻差距和验证方式。
- [部署说明](docs/DEPLOYMENT.md)：GitHub Pages 发布与本地启动。
- [素材来源说明](NOTICE.md)：参考页面、样式、插画的来源及权属说明。

## 本地运行

需要 Node.js 20 或更新版本。运行网站本身不需要安装依赖；测试需要 `npm ci`。

```sh
npm ci
npm test
npm run dev
```

打开 `http://127.0.0.1:4173/`，学习中心位于 `/learn/`。

## 构建

```sh
npm run build
npm run check
```

GitHub 项目站点的构建方式：

```sh
BASE_PATH=/YUkorean/ npm run build
npm run check
```

产物位于 `dist/`，支持直接上传到任何静态网站托管。

## 可使用的学习功能

| 模块 | 当前版本 |
| --- | --- |
| 官网 | 25 个公开展示及指南页面，保留公开视觉资源 |
| 40 音 | 40 个字母、发音提示、系统朗读、掌握标记、听音测验 |
| 兔莉日记 | 90 天、9 章、270 道练习、故事对话、翻译、词汇、语法与写作保存 |
| 词汇 | 376 个单词、搜索、分类、收藏、例句朗读 |
| 复习 | 收藏词的间隔重复：记住后 1/2/4/8…天，忘记后 10 分钟 |
| 语法 | 42 个语法点、例句、选择题、课程进度 |
| 阅读 | 12 篇分级短文、逐句朗读、翻译、理解题 |
| 对话 | 36 个场景、OpenAI 服务端对话、纠错、建议与账号会话记录 |
| TOPIK | 38 道自编风格练习，答题、交卷、评分、解析、错题重练 |
| 听写 / 电台 | 系统语音听写、文本比对、故事朗读 |
| 解词屋 | 本地词汇及语法匹配，不是生成式 AI |
| 个人记录 | 学习天数、连续学习、热力图、进度、句子笔记、JSON 导入导出 |

访客进度使用 `localStorage`；云端登录后，进度保存到独立账号数据库并自动同步。用户输入通过转义渲染，不会作为 HTML 执行。网站不处理生产支付或用户密码。云端应用通过服务端凭证调用 OpenAI，前端不包含后台密钥。未配置凭证时会明确报错。

## 自动部署

推送 `main` 后，`.github/workflows/pages.yml` 自动执行测试、构建、资源链接检查，并发布到 GitHub Pages。

目标仓库：`Saman-max/YUkorean`。预期项目站点路径：`/YUkorean/`。实际发布结果以 GitHub Actions 及 Pages 返回的地址为准。

## 云端后端

完整服务源码在 `cloud-app/`。GitHub Pages 负责前端托管，不能单独运行服务端；登录与 AI 由云端站点承接。密钥配置与当前验证范围见 [云端服务说明](docs/CLOUD_BACKEND.md)。
