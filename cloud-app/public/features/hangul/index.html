把陌生的字，读成第一句话。

韩文把字母组合成一个个音节块。兔莉的40音板块提供认读、书写、拼读与测验入口，让你从认识字形走到读出常用词。

“40音”是入门课程里常见的说法，指21个元音和19个辅音的学习集合，不代表韩语只有40种实际发音。

01

先看结构，再练声音

从基本元音、基本辅音开始，观察字母在音节里的位置。用 가、나、다 等短音节练习，再把字母放回 가방、나무 这样的词里。书写帮助辨认字形，听音和开口帮助建立声音联系。

가방

包

나무

树

02

把认读、书写、拼读连起来

可以先听一个字母或例词，再写一遍、读一遍，最后遮住提示检查。第一次练习不需要追求速度，优先分清容易混淆的字形；收音与音变随后放在具体单词中练习。

  • 认读：看到字母能辨认它。
  • 书写：留意笔画与音节块的位置。
  • 拼读：从单音节过渡到常用词。
  • 回顾：用测验找出仍需复习的字母。
03

准备好下一步

会认字母之后，用短日记和简单对话巩固。不要长期依赖中文谐音或罗马字；遇到发音疑问，回到音频与口型练习。
